# Figure SX. Cryostage dry-cooling response used for the first-order response model

Suggested caption:

**Figure SX. Dry-cooling characterization of the cryostage plate-temperature response.** (A) Calibrated plate-temperature traces recorded during active dry cooling to fixed reference setpoints of -5, -10, -15, and -20 °C, with three independent runs per setpoint. Each trace is aligned to the first telemetry row with controller power above 1.0. Dotted horizontal lines indicate the corresponding reference setpoints. (B) Mean measured plate-temperature response for each setpoint compared with the calibrated setpoint-dependent first-order response model used in the open-loop trajectory-design workflow. The fitted response-time lookup was \(\tau(T_{ref})=[75.3, 98.2, 98.0, 99.0]\) s at \(T_{ref}=[-20,-15,-10,-5]\,^\circ\mathrm{C}\), and the fitted steady plate-temperature lookup was \(T_\infty(T_{ref})=[-19.8, -14.8, -9.6, -4.7]\,^\circ\mathrm{C}\). Telemetry was recorded with a median sampling interval of 0.111 s, corresponding to approximately 9.0 Hz.
